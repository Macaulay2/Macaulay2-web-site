Homebrew is the preferred way to install Macaulay2 on macOS. See the Macaulay2 homebrew tap for instructions. The disk images in this directory are experimental and are not officially supported; use one only if Homebrew is not an option for you.

The name of each file below indicates the architecture it was built for (arm64 for Apple silicon, x86_64 for Intel) and, for the older files, the version of macOS it was built on. Older disk images are kept here for reference and are unlikely to run on a current system.

These disk images are not signed or notarized

We do not sign these disk images with an Apple Developer ID certificate, and we do not submit them to Apple for notarization. (The programs and libraries inside are "ad hoc" signed, which is enough for them to run, but it carries no developer identity.) As a result, macOS Gatekeeper will refuse to open a disk image downloaded from this page, reporting that it cannot verify that the file is free of malware. Step 2 below works around that.

Installation

  1. Download the .dmg file below that matches your machine.

  2. Remove the quarantine flag that your browser attached to the download. In a Terminal window: 

    	xattr -d com.apple.quarantine ~/Downloads/Macaulay2-*.dmg

    (If the response is "No such xattr: com.apple.quarantine", the file was not quarantined and there is nothing to do.) Alternatively, double-click the disk image, dismiss the warning, then open System Settings, go to Privacy & Security, and click "Open Anyway".

  3. Double-click the disk image to mount it, then drag the Macaulay2-VERSION folder onto the Applications shortcut beside it.

  4. Run Macaulay2 once from its new location and evaluate setup(), which offers to put M2 on your PATH and to configure Emacs: 

    	/Applications/Macaulay2-VERSION/bin/M2

    Alternatively, add /Applications/Macaulay2-VERSION/bin to your PATH yourself.
