This is a package archive for the Macaulay2 Emacs package, which provides a major mode for editing Macaulay2 code and for running Macaulay2 sessions in Emacs, along with other related Emacs packages. To use it, add the following to your Emacs init file (e.g., ~/.emacs): 

(require 'package)
(add-to-list 'package-archives '("M2" . "https://macaulay2.com/Repositories/Emacs/") t)
(package-initialize)

Then run M-x package-refresh-contents followed by M-x package-install RET M2 RET. The other packages available here may be installed in the same way, or browsed using M-x list-packages.
